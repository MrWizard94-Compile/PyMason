# PyMason — Learn here. Keep building for life.

**Product idea:** Students should not “graduate *off* PyMason.” They graduate **through** it — from blocks to dual edit to Free Python to multi-module portfolios — and still open the same forge years later for sketching, teaching, and shipping small tools.

---

## The continuum

```
Tour & blocks  →  Dual (blocks + text)  →  Free Python  →  Modules & tests
      ↓                    ↓                      ↓                ↓
  Classroom          Fluency habits          Pro profile      Portfolio / GitHub
```

| Stage | How PyMason shows up | Career-relevant skill |
|-------|----------------------|------------------------|
| **Learner** | Tour, Core toolbox, examples, paths | Structure before syntax |
| **Classroom** | Educate menu, assignments, autograde | Feedback loops, rubrics |
| **Professional** | Full toolbox, Dual/Free, portfolio export | Real files, modules, README, tests |

You never throw away the visual graph: **Python → Blocks** and workspace JSON remain reverse doors.

---

## Product features that support lifelong use

| Feature | Why it matters after class |
|---------|----------------------------|
| **Real `.py` download** | Artifact lives outside the product |
| **Dual / Free Python** | Same app as a sketchpad when blocks feel slow |
| **AST import** | Bring “real” scripts back into structure |
| **Multi-module projects** | Matches how pros organize code |
| **Career templates** | CLI, data, class lib, API client, test-first |
| **Portfolio package** | README + main.py + tests + workspace JSON |
| **Debugger / asserts** | Professional verification habits |
| **AI Apply** | Co-pilot that edits structure, not only chat |
| **Profiles** | Learner / Classroom / Pro without forking the app |

---

## What we are *not*

- Not a district LMS (Code.org still owns scale ops).
- Not VS Code (monorepos, extensions, remote SSH).
- Not a dead-end curriculum player.

**We are the forge that stays open.**

---

## Teacher talking points

1. *“You’ll use this same tool after the course.”*  
2. *“Your final is a portfolio folder, not a quiz.”*  
3. *“Blocks teach structure; Free Python is the same file you’ll run on a laptop at work.”*
