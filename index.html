Help & Reference

            
        

        

            
Getting Started

            
    
                
    • 
                
  • Drag blocks from the toolbox (left) onto the workspace
    • 
                
  • Snap them together — Python appears live on the right
    • 
                
  • Click Run (or Ctrl+Enter) to execute with Pyodide
    • 
                
  • Try an Example to see a complete program
    • 
            

            
Keyboard Shortcuts

            
    
                
  • Ctrl+Enter — Run code
    • 
                
  • Ctrl+S — Save workspace
    • 
                
  • Ctrl+Shift+S — Export workspace JSON
    • 
                
  • Ctrl+D — Download .py
    • 
                
  • Ctrl+F — Search blocks
    • 
                
  • Ctrl+0 — Zoom to fit workspace
    • 
                
  • Ctrl+Shift+L — Copy share link
    • 
                
  • Ctrl+C — Copy Python (no block selected)
    • 
                
  • Ctrl+Z / Ctrl+Y — Undo / Redo
    • 
                
  • F1 — Toggle this help panel
    • 
                
  • Esc — Close flyout / dialogs / exit tour
    • 
                
  • ← / → — Tour back / next
    • 
            

            
Studio Features

            
    
                
  • Tour — step-by-step click-through of the studio (replay anytime)
    • 
                
  • Share — copy a link that restores this workspace
    • 
                
  • Paths — short guided challenges
    • 
                
  • Packages — micropip install for pure-Python libs
    • 
                
  • History — recent run outputs; click to restore
    • 
                
  • Map — workspace minimap
    • 
                
  • Right-click a block → Add to Favorites
    • 
                
  • Click red error lines with line numbers to jump to the block
    • 
            

            
Python Quick Reference

            
    
                
  • print(x) — I/O → print
    • 
                
  • input("…") — I/O → input
    • 
                
  • if / elif / else — Logic
    • 
                
  • for / while — Loops
    • 
                
  • def / return — Functions
    • 
                
  • class / self — Classes
    • 
                
  • try / except — Errors
    • 
                
  • import — Imports (dropdown presets)
    • 
                
  • list / dict / set / tuple — Data structures
    •

Tips

            
    
                
  • Select a block to highlight its lines in the code panel
    • 
                
  • Click a code line to highlight the matching block
    • 
                
  • Right-click a block → Show Python or Disable
    • 
                
  • Disconnected blocks show a warning icon
    • 
                
  • Missing required inputs get a red dashed outline
    • 
                
  • Workspaces auto-save every 30 seconds
    •
